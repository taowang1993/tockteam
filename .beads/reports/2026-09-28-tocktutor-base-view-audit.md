# TockTutor Base View Audit — September 28, 2026

**Update:** This report records the pre-fix audit. All 13 findings were subsequently addressed; see [the remediation report](2026-09-28-tocktutor-base-view-remediation.md) for fixes and verification.

**Snapshot:** `main` at `de57b887`; issue `tockteam-wlv5`. Three independent, read-only subagents reviewed (1) parser/query/evaluator, (2) browser interactions and authoring, and (3) runtime/vault boundaries. The parent inspected the cited current source, reproduced six evaluator/query cases directly from `src/`, and ran focused tests. No implementation was changed. The modified `AGENTS.md` predates this audit and was not touched.

**Scope:** Bounded executable `.base` views on the Desktop TockTutor surface, including note hydration, formulas, selection, cell edits, and runtime save. The full Obsidian Bases toolbar/results/table parity explicitly excluded in `plugins/tocktutor/parity/ledger.json` (`obsidian-071`) is not a defect in this report. All three review lenses—simplification, security/hardening, and performance—were applied. There is **no confirmed authorization, path-traversal, script-execution, or cross-vault vulnerability** in this audited path.

## Confirmed Findings — 13 Total

1. **[P1] Two revision-checked saves can overwrite one another.** Impact: two windows or Base cell edits using the same revision can both pass the asynchronous final check and rename their temporary files; the last write silently replaces the first, while both callers may report success. **Affected:** `plugins/tocktutor/packages/tockbot-note-runtime/src/index.ts:1603–1635,6603–6665`. The final `assertWriteTargetUnchanged()` and `rename()` have no per-target serialization. **Fix:** lock by canonical document path around revision check, commit, and result inspection; add a deterministic two-writer conflict test. **Status:** Unfixed; independently checked reachable interleaving in current source, but no live race fixture was run.

2. **[P1] A valid numeric Base summary can crash rendering.** Impact: `sum(file.properties)` on an ordinary hydrated note reaches `Number()` on a null-prototype object and throws `TypeError` instead of showing an unsupported expression. `range(file.properties)` has the same conversion path. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/NotesBaseFormula.ts:2341–2347,2385–2397`, `src/base-query.ts:85–101,182–201`. **Fix:** reject unsupported object operands before numeric coercion and return an unsupported summary. **Status:** Unfixed; reproduced by parsing a valid Base and calling `createBaseViewModel()` against two valid note snapshots (`TypeError: Cannot convert object to primitive value`).

3. **[P1] `concat()` bypasses the bounded formula-output limit.** Impact: `concat("x".repeat(100000), "x")` produces 100,001 characters despite the 100,000-character limit; chained formulas can grow exponentially during synchronous rendering. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/NotesBaseFormula.ts:74,2325–2328`. **Fix:** check cumulative length before joining, return unsupported on overflow, and test the small boundary case rather than a memory-exhaustion fixture. **Status:** Unfixed; direct source invocation returned `{ supported: true, length: 100001 }`. Actual memory exhaustion was not attempted.

4. **[P1] Switching panes can discard a pending Base cell edit.** Impact: pointer-down in pane B changes the focused pane before pane A's text input blur submits; A's bound `onBaseEdit` rejects the unfocused callback and the entered text is reset, contrary to the independent-pane-draft contract. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/route.tsx:3138–3154,5544–5553,6341–6346`, `src/base-executable-view.tsx:193–225`. **Fix:** bind the edit to the originating pane/document lifetime and vault, retaining revision checks; test pointer-down → blur across split panes. **Status:** Unfixed; event-order and guard path independently confirmed in source. Live pointer-flow reproduction was not run.

5. **[P2] Changing a note leaves an already-loaded Base stale.** Impact: edits, moves, and new/deleted Markdown notes do not invalidate hydrated Base rows; filters, summaries, exports, and editable row revisions can remain wrong until the `.base` itself reloads. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/route.tsx:1748–1765,2683–2702,2734–2778,2827–2860`. Vault events refresh the tree and Markdown relationships, but omit Base hydration; the successful revision cache stays valid. **Fix:** invalidate affected Base hydration on vault inventory/content events and coalesce a bounded reload. **Status:** Unfixed; confirmed by the current event and hydration paths, not tested live.

6. **[P2] One unreadable note makes a Base look empty.** Impact: a disappearing or oversized Markdown note rejects one `Promise.all` batch; hydration publishes no rows or error and the view says “No notes match this view.” Valid rows disappear without explaining the incomplete load. The default runtime note-read limit is 256 KiB. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/route.tsx:4026–4044`, `src/base-executable-view.tsx:575–578`; `plugins/tocktutor/packages/tockbot-note-runtime/src/index.ts:70`. **Fix:** expose loading/failure separately from a successful empty result, with retry; only show partial rows when explicitly marked incomplete. **Status:** Unfixed; failure and UI fallback confirmed by source; no delayed/failing Remote fixture run. This consolidates both reviewers' hydration-failure observations.

7. **[P2] A Base cell save can start or finish after route disposal.** Impact: `applyBaseEdit()` passes no owned abort signal, does not recheck disposal after its read, and is not tracked by `document.saving`; `dispose()` may finish and unmount the Remote before the edit settles. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/route.tsx:4058–4074,4426–4454`, `src/client-api.ts:46–52`. **Fix:** register Base edit flights with document lifecycle, stop precommit continuation after disposal, and await already-started mutations during teardown. **Status:** Unfixed; lifecycle path confirmed by source, asynchronous teardown fixture not run.

8. **[P2] A rejected numeric edit remains visible as if saved.** Impact: clearing a number input changes its local text; `createExecutableBaseFrontmatterEdit()` rejects the empty value, but `emit()` returns before error feedback or rollback. Calculations and export still use the old number. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/base-executable-view.tsx:175–225`, `src/base-edit.ts:23–49`. **Fix:** distinguish invalid input from unchanged input; restore the authoritative value and show validation feedback. **Status:** Unfixed; confirmed by source control flow; no new component regression test run.

9. **[P2] Base hydration checks its total-byte budget only after fetching the data.** Impact: the route can fetch and retain 2,000 readable notes before `base-query.ts` rejects more than 16 MB; with the default 256 KiB per-note read limit, the upper bound is approximately 500 MiB plus transfer and parsing overhead. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/route.tsx:4026–4041`, `src/base-query.ts:16–18,166–177`. **Fix:** enforce the same aggregate limit while scheduling/fetching, including checks on actual returned bytes, and surface a limit error. **Status:** Unfixed; structural resource bound confirmed, memory/latency not benchmarked.

10. **[P2] An `if()` condition comparing string literals chooses the wrong branch.** Impact: `if("a" == "b", 1, 0)` returns `1`; the nested evaluator's greedy quoted-literal match treats the full condition as a truthy string. Filters using such conditions can admit wrong rows. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/NotesBaseFormula.ts:833–843`. **Fix:** accept quoted literals only when they form a single complete token; otherwise evaluate the expression. **Status:** Unfixed; direct source invocation returned `{ supported: true, value: 1 }`.

11. **[P2] Bare constant expressions disagree with their parenthesized equivalents.** Impact: a displayed formula `1` is unsupported while `(1)` returns 1; bare `true` resolves as a missing property (`undefined`) while `(true)` returns the Boolean. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/NotesBaseFormula.ts:833–843,2238–2248`. **Fix:** use one bounded scalar-literal parser before property lookup in both evaluator paths, without loosening string validation. **Status:** Unfixed; all four outputs reproduced from current source.

12. **[P2] Quoted filter-list expressions are unquoted twice.** Impact: a valid YAML item `- '"a" == "a"'` becomes `a" == "a` and the view reports an unsupported expression instead of matching rows. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/base-parser.ts:105–112`, `src/NotesBaseFilterTree.ts:42–47,65–71`. **Fix:** decode the YAML scalar once; the filter-tree parser must not strip expression quotes again. **Status:** Unfixed; valid Base parsed into a corrupted statement and `createBaseViewModel()` reported it unsupported in a direct source probe.

13. **[P2] Searching can invalidate otherwise valid cross-file summaries.** Impact: a formula `file("B.md").size` on A and B contributes to `sum(formula.size)` without search, but searching for A hides B from a newly reconstructed file context; the summary becomes unsupported even though A's displayed value remains valid. **Affected:** `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/base-query.ts:224–238`, `src/base-view-model.ts:124–135`. **Fix:** preserve the complete hydrated file-lookup context when recomputing summaries for visible rows. **Status:** Unfixed; direct source probe returned sum `2` without search, then no summary and `unsupported: sum(formula.size)` with search `A`.

## Verification

Focused checks run fresh from `plugins/tocktutor/packages/tockteam-tocktutor-workbench`:

```sh
node --test tests/base-executable-port.test.ts tests/base-formula-port.test.ts tests/base-authoring.test.ts tests/base-note.test.ts
pnpm exec vitest run tests/base-executable-view.test.tsx tests/base-new-note-dialog.test.tsx --environment jsdom
node --test --test-name-pattern='[Bb]ase' tests/route.test.ts
```

**Result:** 22/22, 24/24, and 14/14 passing (60 passing total). The `route.test.ts` run printed React's `useLayoutEffect` server-render warning; no test failed. These suites do **not** contain regression cases for the findings above. `route.test.ts` and `base-note.test.ts` import built `dist/`; the six direct source probes used `node --input-type=module -e` with `src/NotesBaseFormula.ts`, `src/base-parser.ts`, and `src/base-view-model.ts` to avoid relying on generated outputs. The parent checked `git status` and HEAD after testing; `AGENTS.md` remained the sole pre-existing tracked modification before this report.

**Not verified:** A live Desktop Base flow, app screenshots, pointer/keyboard behavior, a deterministic two-writer save race, memory benchmark, full repository build/typecheck, or installed smoke. No app/browser/server was launched. Environment limitations are not counted as confirmed bugs. The three subagent reviews were source-only; the parent reproduced the six expression/query cases and independently inspected the other cited flows. No fixes are claimed.

**Verdict:** Needs attention before describing the Base feature as reliably conflict-safe and bounded. Audit complete; remediation requires a separate implementation task.

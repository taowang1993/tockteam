## Source and Rights Boundary

The installer fetches only a selected extension's source blobs from `raycast/extensions` on public GitHub. It pins the commit, selected extension tree, Git blob SHA-1 for every regular file, and whole-source SHA-256. It rejects links, traversal, oversized files, unreviewed package configuration, missing lockfiles and non-MIT extension manifests. It never queries an unofficial Raycast Store download endpoint or treats the Store's Raycast-only Install action as a TockTeam bundle. GitHub API rate limiting falls back to a read-only, partial Git clone with no checkout, hooks, credential helpers or inherited Git configuration. This is a source-license choice, not a legal conclusion about Store downloads or a blanket license audit of bundled dependencies.

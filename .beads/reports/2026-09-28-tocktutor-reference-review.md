# TockTutor Reference and Bug Review

Reviewed on 2026-09-28. Tracking: `tockteam-oymp`. This is a focused comparison of `.agents/references/tocktutor.md` against the mounted TockTutor package, route/client wiring, package manifests, and existing behavior tests; it is not a full security audit of every plugin.

## Reference Changes

The published DSH pin (`0.1.2-rc.1`), nine package versions, Desktop-only bundle composition, slot names, parity totals, and build scripts matched the current manifests. The Workbench description had missed the **mounted** 20-command Live Preview slash menu and the newer `.base` creation, view editing, Find, and note-creation workflows. The integration-limits section incorrectly described slash commands as entirely helper-only, and described the now-repaired bookmark behavior as unavailable. The reference now distinguishes the mounted menu from the separate unmapped `resolveSlashCommand()` helper, records Base authoring, and states the remaining Page Preview/graph/block-bookmark limits without claiming unverified parity.

## Confirmed Findings — 5

1. **[P2] An invalid Base becoming valid crashed its view on render.** Impact: when a `.base` source changed from malformed to supported (or back) while its view stayed mounted, React detected a different number of hooks and threw `Rendered more hooks than during the previous render`, preventing recovery in the current view. Affected path: `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/base-executable-view.tsx`. **Fixed:** the column/property memo now runs on both render paths, returning an empty list for invalid documents before the existing alert. Verification: the new source-transition regression failed with the exact React hook-order exception before the fix and all 22 Base-view component tests passed afterward.

2. **[P2] Duplicate bookmark IDs across a group could erase two entries with one Remove action.** Impact: malformed or migrated browser storage with a grouped child and top-level record sharing an ID loaded both; `removeBookmark(id)` removed both, rather than the selected row. Affected path: `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/bookmarks.ts`. **Fixed:** load skips conflicting records, and saves reject all duplicate IDs, including duplicates within a group; original stored bytes are not rewritten on load. Verification: the node regression failed before the fix and passes against the rebuilt package; the group-removal assertion confirms only the selected record is removed.

3. **[P2] Saved Web Viewer links could not reopen from Workbench Bookmarks.** Impact: a user could save a page, see its link in the Workbench list, and click a button that did nothing. Affected paths: `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/route.tsx`, `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/web-viewer-panel.ts`, and `plugins/tocktutor/packages/tockbot-web-clip/src/client.tsx`. The route delegated link records to `openBookmark()`, which returns `false`; unchanged URL props also suppressed a second navigation after the viewer visited another page. **Fixed:** the Workbench routes a saved link to the existing isolated Web Viewer and issues a distinct navigation request on every activation. The viewer still validates and fetches through its existing Host/isolated-frame boundary, not native or ordinary browser navigation. Verification: a route-level link test and a viewer test both failed before the fix; the integrated same-URL reactivation test and full focused suites pass.

4. **[P2] Grouped bookmarks vanished behind a nonfunctional group row.** Impact: moving a bookmark into a saved group made it inaccessible from the Workbench list, even though its record remained stored. Affected path: `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/utility-panel.tsx`. The panel rendered only top-level records and treated a group as an openable bookmark, though the controller has no group-open action. **Fixed:** groups now show their bounded children as indented, directly actionable rows, with a semantic group label rather than a dead button; existing remove behavior remains available. Verification: the grouped-row component regression failed before the fix and passes afterward.

5. **[P2] Page Preview offered a working-looking switch without a preview.** Impact: users could toggle and save a preference that has no mounted hover-preview consumer. Affected path: `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/utility-panel.tsx` (the persisted model remains in `plugins/tocktutor/packages/tockteam-tocktutor-workbench/src/settings.ts`). **Fixed:** removed the misleading switch from Settings and Workspaces while keeping stored settings compatible; no hover-preview feature is claimed. Verification: the component regression failed before the fix and passes afterward; the neighboring Backlinks in Document control still works.

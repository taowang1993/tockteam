# Vault Watcher Gate

## Scope and Cause

CI `35815843690` passed Windows, Linux, both macOS core jobs, and Nix, but exposed a Linux Runtime failure: Node's recursive watcher remained attached to the retired inode after atomic note replacement. Disk contents changed while `note-vault/change` stopped refreshing linked panes.

Replaced that watcher with exact `chokidar@5.0.0`. Retained nonpersistent operation, canonical path/generation checks, symlink exclusion, hidden-path filtering, and atomic saves. Initial document/tree/inspection reads wait cancellably for readiness. Disposal awaits current and retired watcher cleanup. A 50 ms stability window retains the final edit in a burst.

Independent review found and then accepted corrections for Windows root equivalence, nonpersistent native-error forwarding, and write-finish polling surviving close. The latter two use a narrow pnpm patch, registered identically in both workspace configurations and locks. The staged runtime resolves the patched copy, not the unrelated Chokidar used by pinned DSH. No pinned DSH or installed dependency was hand-edited.

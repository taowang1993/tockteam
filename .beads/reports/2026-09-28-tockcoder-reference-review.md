# TockCoder Reference and Code Review — 2026-09-28

## Scope

Snapshot review of `.agents/references/tockcoder.md` against pinned `dsh-source.json` (`0.1.2-rc.1`), the Desktop/Web composition, browser sidebar/review and Better Sidebar adapter contracts. The existing reference correctly describes the major ownership and DSH service contracts, but omitted runtime sidebar settings, Desktop-only browser/open-path behavior, and Review display limits; those details are now documented. For Review UX, the design goal was to keep a rejected branch name editable and leave refresh errors visible without changing the existing layout. This review does not audit all of the pinned DSH runtime or every upstream Host operation.

## Confirmed Findings: 5

1. **[P1] Sending a review request and switching sessions can send the same comments twice.** Impact: after a cleared composer creates a pending delivery, a session switch discards that pending acknowledgement before DSH publishes the durable user message. Returning to the first session reinserts the already-sent review request. Affected path: `plugins/sidebar/src/client/review-comments.ts` (`createComposerBridge.reconcile`, `watch`). Fix/verification status: fixed in `4d72dfe2`, then simplified the resumed-event scan in `9cbd6d99`. The new regression failed before the fix (`1 !== 0`) and passed afterward, including two independent pending sessions.
2. **[P2] A failed legacy-storage write hides saved review comments.** Impact: during migration from `tockteam.desktop-sidebar.review-comments.v1`, a quota/permission failure writing the new key is caught by the same handler as the legacy read, returning an empty array instead of keeping comments in memory. Affected path: `plugins/sidebar/src/client/review-comments.ts` (`readComments`). Fix/verification status: fixed in `4d72dfe2`. The new legacy-storage regression failed before the fix (`0 !== 1`) and passed afterward.
3. **[P2] POSIX backslashes and parent segments can redirect file-open interception.** Impact: the browser treats a literal backslash in a POSIX filename as a separator and treats `/workspace/../outside` as a child. It can show a Files panel error instead of handing the actual path to the DSH opener. The Better Sidebar Host still enforces its own file boundary; this is an incorrect client decision, not proven Host file disclosure. Affected paths: `plugins/sidebar/src/client/plugin.tsx` (`pathBelongsToActiveWorkspace`) and `plugins/sidebar/src/client/better-sidebar-api.ts` (existing platform-aware path normalization). Fix/verification status: fixed in `4d72dfe2` by reusing the platform-aware path normalizer for both navigation and interception. The guarded browser check first failed with no calls to the original opener, then passed; focused POSIX/Windows path checks passed.
4. **[P2] A failed branch creation clears the typed branch name.** Impact: `mutate` catches the Host failure but resolves normally; the New Branch button then unconditionally clears the input, forcing a user to retype a rejected or temporarily failed branch name. Affected path: `plugins/sidebar/src/client/plugin.tsx` (`WorkspacePanel.mutate` and New Branch action). Fix/verification status: fixed in `4d72dfe2`. The guarded browser check failed with an empty input before the fix, then passed with the rejected name retained and the error visible.
5. **[P2] A failed Review refresh hides its own error after a successful Git action.** Impact: `refresh` catches and displays a status error, then `mutate` unconditionally clears that error; stale branch/change data remains without explanation. Affected path: `plugins/sidebar/src/client/plugin.tsx` (`WorkspacePanel.refresh` and `mutate`). Fix/verification status: fixed in `4d72dfe2` by letting the refresh own its own success/error state. The guarded browser check timed out while waiting for the swallowed error before the fix, then passed with that error visible.
